## ⛔ 건드리기 전에 반드시 읽을 것

### 1. 이름은 화면이 아니라 «자료» 에도 박혀 있다

`PKEMS` → `PEER` → `TRACE` 로 두 번 바뀌었습니다. 잘못 건드리면 **쓰던 사람의 기록이 통째로 없는 것이 됩니다.**

| 어디 | 지금 | 이어받는 법 |
|---|---|---|
| 드라이브 | `TRACE-index.json` · `TRACE-settings.json` | `findOrInherit()` · 옛 이름을 최근 것부터 찾아 **파일 ID 는 그대로 두고 이름만** 바꾼다 |
| localStorage | `trace.*` | `inheritOldKeys()` · `peer.*` → `pkems.*` 순. **옛 키는 안 지운다** |
| IndexedDB | **`pkems` 그대로** | 아직 못 올린 사진이 들어 있다. 화면에 안 보이는 이름이라 안 바꾼다 |

**저장 키를 건드렸으면 `이름바꾸기.mjs` 를 반드시 돌리세요.** 화면 결함이 아니라 **자료 사고**입니다.

### 2. 색인은 커지면 조각으로 갈린다

256KB 를 넘으면 `TRACE-index.json` 이 «목차» 가 되고 기록은 `TRACE-index-00.json` … 으로 갑니다.

- **조각을 못 읽으면 저장을 멈춥니다** (`indexIncomplete`). 반쪽으로 덮어쓰면 그 조각이 통째로 지워집니다
- **조각을 먼저, 목차를 나중에** 올립니다
- 옛 버전이 목차를 덮어써도 남은 조각을 이름으로 찾아 함께 읽습니다 (`readStrayShards`)

**`saveIndex`·`loadIndex` 를 건드렸으면 `색인쪼개기.mjs` 를 돌리세요.**
「조각을 못 읽으면 한 글자도 덮어쓰지 않는다」 가 빨개지면 **그대로 배포하지 마세요.**

### 3. 모양은 레고 하나 · 고르는 축은 셋이다

| 축 | 붙는 곳 | 쥐는 것 |
|---|---|---|
| 모양 | `data-theme="lego"` (고정) | 글꼴 · 모서리 · 돌기 · 여백 · 머리띠. **색 없음** |
| 색감 | `data-tone` | 종이 · 잉크 · 강조 · 유형 여섯. **모양 없음** |
| 밝기 | `data-mode` | (없음)=기기 따름 · light · dark |
| 글자 | `data-size` | (없음) · big(새 사용자 기본) · huge |

- **옛 모양 키(play·memo·brick·note·base·paper·draft)를 지우면 안 됩니다.**
  설정·공유 링크·뽑아낸 HTML 에 남아 있습니다. `themeOf()` 가 모르는 키를 레고로 받아 주고,
  옛 키로 넘어오는 사람은 `normalizeSettings()` 가 **그 모양이 입던 색감**을 물려줍니다
- 공유 링크에는 이제 **색감(tn)** 도 실립니다. `view.html` 의 색감 블록은 `index.html` 과 같은 팔레트여야 합니다
- 모양 블록에 색을 적지 마세요. 예외는 «가리키기» 뿐 · `var(--brand)` · `var(--panel)`
- 색을 하나라도 손댔으면 **`대비점검.mjs`** 를 돌리세요

### 4. 자리와 이름은 앱이 정하지 않는다

앱이 정하는 것은 **새로 만드는 것** 뿐입니다. 이미 드라이브에 있는 것은 **드라이브가 진실**입니다.

| 무엇 | 앱이 만든 것 | 밖에서 온 것 (`srcId`) |
|---|---|---|
| 자리 | 정리 방식대로 | **사람이 둔 곳 그대로** · 훑을 때마다 다시 잡는다 |
| 이름 | 이름 규칙대로 | **사람이 붙인 그대로** · 「📛 이름 정리」로만 바뀐다 |
| 지우기 | 파일도 휴지통으로 | **목록에서만 뺀다** |

- `srcPath` 는 «정해 둔 자리» 가 아니라 **«마지막으로 본 자리»** 입니다. `relearnPlaces()` 가 훑을 때마다 다시 잡습니다
- 이미 있는 파일을 옮기는 것은 **`n._relocate` 가 섰을 때만** 입니다 (설정 → 「기존 파일도 새 방식으로 옮기기」)
- `uploadFile` 에 이름을 **안 주면** 드라이브의 이름을 그대로 둡니다. 이미 있는 파일에는 대개 안 주는 것이 맞습니다
- 연결한 폴더 **밖**으로 나가면 `drive.file` 권한으로는 아예 안 보입니다. 그때는 **안 보인다고 말합니다** (`_missing`)


**파일 이름은 조각 다섯입니다** (`NAME_PARTS`). 화면은 켜고 끄는 칸이지만,
**설정에 적히는 것은 여전히 `{날짜}_{태그}_…` 꼴의 규칙 문자열**입니다.
그래야 이름을 만드는 자리(`applyPattern`·`attachName`·`mdName`·「📛 이름 정리」)가 하나도 안 바뀝니다.
조각 밖의 토큰을 쓰는 옛 규칙은 `isSimplePattern()` 이 가려내어 **손대지 않습니다.**

**정리 방식은 둘입니다** (`기록마다 폴더 하나` · `한 폴더에 전부`).
옛 셋(`materials`·`monthly`·`tag`)은 **목록에서만 뺐고 코드에서는 그대로 돕니다** ·
`OLD_FOLDER_MODES` 에 있습니다. **여기서 지우면 그 방식을 쓰던 사람의 설정이 기본값으로 되돌아가고,**
**다음 저장부터 파일이 딴 곳에 쌓입니다.** 이름을 찾을 때는 `folderModeLabel()` 을 쓰세요.

**여기를 건드렸으면 `자리와이름.mjs` 를 반드시 돌리세요.** 화면 결함이 아니라 **자료 사고**입니다.

### 5. 설명을 붙이지 마세요

쓰기 전에 읽어야 할 글이 있으면 **사람들은 그냥 안 씁니다.**

1. 화면이 이미 말하는 것(단추 이름·라벨·자리글)은 설명하지 않는다
2. 남길 것은 «되돌릴 수 없는 것» 과 «안 되는 것» 뿐
3. 그것도 한 줄로, **그때만**

점검 둘이 이걸 지킵니다 · 「첫 화면에 긴 설명이 없다」 · 「녹음 창에 설명이 없다」.
빨개지면 설명을 또 붙인 것입니다. 정 필요하면 `title` 속성에 넣으세요.

### 6. 긴 줄표는 쓰지 않습니다

저장소 어디에도 없습니다. 문장 끝이면 마침표, 그 밖에는 가운뎃점(·).

## 🕳️ 함정 모음 · 그냥 지나가세요

| 함정 | 어떻게 피하나 |
|---|---|
| **띄우기가 죽은 줄 모르고 도구를 의심한다** | 점검이 줄줄이 이상하면 먼저 `curl -s -o /dev/null -w "%{http_code}" http://localhost:8000/`. 200 이 아니면 도구 이야기가 아닙니다 |
| **헤드리스 브라우저가 안 죽고 남는다** | 이어 돌리기 전에 포트 9xxx 짜리 msedge 를 죽입니다 |
| **셸이 백틱·백슬래시를 먹는다** | 정규식·경로·백틱이 든 스크립트는 **Write 도구로** 씁니다 |
| **파이썬 쓰기가 중간에 실패하면 파일이 0바이트** | 한글이 든 파일은 **Write/node** 로 씁니다 |
| **`index.html` 은 CRLF** | 여러 줄 치환은 **Edit 도구**로. node/python 의 `\n` 매칭은 안 걸립니다 |
| **`var()` 는 «선언한 곳» 에서 풀린다** | 카드마다 달라지는 값은 카드에서 풀리게. 덮개(`--veil`)를 걷는 방식 |
| **점검 잣대가 배경 «그림» 을 못 본다** | `backgroundImage` 도 함께 봅니다 |
| **이름이 겹친다** | 「블록」을 찾다가 「블록**놀이**」가 잡힙니다. 이름 칸만 정확히 견줍니다 |
| **점검이 엉뚱한 카드를 집는다** | 검색으로 좁힌 뒤에 누릅니다 |
| **브라우저 도구는 탭을 앞으로 못 세운다** | 바탕화면을 찍어야 하면 사용자에게 부탁합니다 |
| **내 화면에 보이는 것 ≠ 파일에 든 것** | 뽑아낸 파일에 모르는 머리줄이 붙어 있었는데 **크롬 확장**이 끼운 것이었습니다 |
